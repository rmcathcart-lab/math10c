Determining the Domain and Range of a Relation

Every relation has a set of inputs and a set of outputs. Today we read both from ordered pairs, tables, arrow diagrams, graphs and real situations. On a graph, the key picture is the shadow the graph casts on each axis.

I can…
  • state the domain (inputs) and range (outputs) of a relation given as ordered pairs, a table or an arrow diagram, as a list in braces: each value once, in increasing order
  • read the domain and range of a graph as its shadow on the x-axis and on the y-axis
  • use solid endpoints (\le,\ \ge), hollow endpoints (<,\ >) and arrows (no end) to write set-builder notation such as \{y\mid y\ge -3,\ y\in\mathbb{R}\}
  • find the domain and range of a circle or ellipse from its centre and how far it reaches
  • restrict the domain and range of a real situation to values that make sense, using W for counts and \mathbb{R} for measurements

A \{h\mid 120<h<195,\ h\in\mathbb{R}\}

1

Domain and Range Defined

The domain of a relation is the set of all values taken by the independent variable: the inputs, usually x. The range is the set of all values the relation actually produces for the dependent variable: the outputs, usually y.

A relation may be presented as a set of ordered pairs, a table of values, an arrow diagram (mapping diagram), an equation, a graph, or in words. Whichever form is given, the same two questions apply:

Domain Which input values are used?
Range Which output values are produced?

How the answer is written

Finitely many values → a list
Inside braces, each value written once and in increasing order:
D=\{2,\ 5,\ 9\}
Infinitely many values → set-builder notation
R=\{y\mid y\ge -3,\ y\in\mathbb{R}\}
read “the set of all y such that y\ge-3 and y is a real number.”

The symbols N, W, I, Q and \mathbb{R} name the number set the variable is drawn from (tap a card):

N
natural numbers 1,\ 2,\ 3,\ \dots
W
whole numbers 0,\ 1,\ 2,\ 3,\ \dots
I
integers \dots,-2,-1, 0,1,2,\dots
Q
rational numbers: fractions, like \tfrac{3}{4} or -2.5
\mathbb{R}
real numbers: every point on the number line
!
\mathbb{R} is not R. In this unit the real numbers are written \mathbb{R} (double-struck), so they are never confused with R for a range. For a count, use W (whole numbers), or I together with a lower bound such as n\ge0, because I on its own includes negative numbers.
Example 1

Domain and range from ordered pairs

List the domain and range of each set of ordered pairs.

(a) (2,3),\ (0,7),\ (4,10),\ (6,11),\ (-2,3)
x-coordinates: 2,0,4,6,-2; y-coordinates: 3,7,10,11,3 (the value 3 occurs twice, so it is listed once).
\boldsymbol{D=\{-2,\ 0,\ 2,\ 4,\ 6\}}
\boldsymbol{R=\{3,\ 7,\ 10,\ 11\}}
(b) (5,5),\ (0,5),\ (-5,5),\ (3,11),\ (-9,5)
x-coordinates: 5,0,-5,3,-9; y-coordinates: 5,5,5,11,5 (the value 5 occurs four times, listed once).
\boldsymbol{D=\{-9,\ -5,\ 0,\ 3,\ 5\}}
\boldsymbol{R=\{5,\ 11\}}

Reading Domain and Range from a Graph

The domain is the shadow the graph casts on the x-axis when a light shines straight down onto it; the range is the shadow it casts on the y-axis when a light shines straight across.
!
The range runs from the lowest point to the highest point, wherever those are. They are not always the endpoints.

Three features of the drawing decide the answer

Isolated (discrete) points give a list: the x-coordinates plotted are the domain, the y-coordinates plotted are the range, each value written once.
An arrow on an end means the graph continues forever in that direction, so that side is unbounded: an unbounded domain is written \{x\mid x\in\mathbb{R}\}, and a range bounded on one side only is written \{y\mid y\le 3,\ y\in\mathbb{R}\} or \{y\mid y\ge -3,\ y\in\mathbb{R}\}.
A solid endpoint belongs to the graph, so its value is included and the inequality uses \le or \ge; a hollow endpoint does not belong to the graph, so its value is excluded and the inequality uses < or >.

Arrows: the graph never stops

An arrow is a promise: the graph keeps going in that direction forever, even past the edge of the grid. So its shadow keeps going too, and that side of the inequality has no bound. If the shadow covers a whole axis, the answer is every real number, \{x\mid x\in\mathbb{R}\}.

Example 2

Domain and range from a graph

State the domain and range of each relation graphed below.

(a)
Five isolated points: (-4,-3), (-2,-1), (-1,1), (0,2), (2,1). Discrete, so both are lists; the y-value 1 occurs twice.
\boldsymbol{D=\{-4,\ -2,\ -1,\ 0,\ 2\}}
\boldsymbol{R=\{-3,\ -1,\ 1,\ 2\}}
(b)
A continuous “tent” with solid endpoints at (-4,-1) and (4,-1), so both ends are included: \le. The x-shadow runs -4 to 4; the y-shadow runs from the lowest point y=-1 to the peak y=3.
\boldsymbol{D=\{x\mid -4\le x\le 4,\ x\in\mathbb{R}\}}
\boldsymbol{R=\{y\mid -1\le y\le 3,\ y\in\mathbb{R}\}}
(c)
Two rays leaving (0,3), both arrowed, so the graph spreads left and right without end and falls forever. The highest point is the vertex, y=3.
\boldsymbol{D=\{x\mid x\in\mathbb{R}\}}
\boldsymbol{R=\{y\mid y\le 3,\ y\in\mathbb{R}\}}
Think Graphs (a) and (b) both stay between x=-4 and x=4. Why does (a) get a list and (b) an inequality?
(a) is separate dots: only five x-values are used, so we can list them. (b) is an unbroken line: every x from -4 to 4 is used, decimals included, which is infinitely many values, so we need an inequality.

When an endpoint is open

A solid dot is a point on the graph. A hollow dot marks where the graph stops just before that point: the point itself is missing. There is no “last” point next to the hole, so the best we can say is “up to, but not including”.

Example 3

When an endpoint is open

State the domain and range of each relation. Watch for the hollow endpoints.

(a) A segment from a solid endpoint at (-3,1) to a hollow endpoint at (4,5).
The solid end (-3,1) is included (\le); the hollow end (4,5) is not (<). The x-shadow runs from -3 up to, but not including, 4; the y-shadow from 1 up to, but not including, 5.
\boldsymbol{D=\{x\mid -3\le x<4,\ x\in\mathbb{R}\}}
\boldsymbol{R=\{y\mid 1\le y<5,\ y\in\mathbb{R}\}}
(b) A ray that starts at a hollow endpoint at (1,-2) and continues up to the left forever.
The arrow means the ray goes on forever to the left and upward; the hollow start (1,-2) is not included, so use < and >.
\boldsymbol{D=\{x\mid x<1,\ x\in\mathbb{R}\}}
\boldsymbol{R=\{y\mid y>-2,\ y\in\mathbb{R}\}}
Think Could the domain in (a) be written -3\le x\le 3.999?
No. x=3.9999 is also on the segment, and so is 3.99999. Whatever number below 4 we pick, a bigger one is still on the graph. Only x<4 catches them all.

Closed curves: circles and ellipses

A circle or ellipse has no endpoints and no arrows: it is one closed loop, so every shadow end is included. Its shadows run from its leftmost point to its rightmost, and from its lowest point to its highest. For a circle with centre (h,k) and radius r, those are h-r to h+r across and k-r to k+r up and down.

Example 4

Curves, ellipses, arrow diagrams and a circle

State the domain and range of each relation described below.

(a)
Arrows on both ends: the curve continues outward and upward forever, so every real x is eventually used. The lowest point is (0,-3) and there is no upper limit.
\boldsymbol{D=\{x\mid x\in\mathbb{R}\}}
\boldsymbol{R=\{y\mid y\ge -3,\ y\in\mathbb{R}\}}
(b) An ellipse, with horizontal axis u and vertical axis v.
Centred at the origin with horizontal semi-axis 3 and vertical semi-axis 2.
\boldsymbol{D=\{u\mid -3\le u\le 3,\ u\in\mathbb{R}\}}
\boldsymbol{R=\{v\mid -2\le v\le 2,\ v\in\mathbb{R}\}}
(c)
The domain is the set of inputs on the left; the range is the set of outputs actually reached on the right. Both 5 and 9 map to 1, so 1 is listed once.
\boldsymbol{D=\{5,\ 7,\ 9\}}
\boldsymbol{R=\{1,\ 3\}}
(d) A circle with centre (3,-2) and a radius of 6.
For centre (h,k) and radius r the domain runs from h-r to h+r and the range from k-r to k+r. Here h=3, k=-2, r=6:
3-6=-3 to 3+6=9; -2-6=-8 to -2+6=4.
\boldsymbol{D=\{x\mid -3\le x\le 9,\ x\in\mathbb{R}\}}
\boldsymbol{R=\{y\mid -8\le y\le 4,\ y\in\mathbb{R}\}}

Domain and Range in Real-World Situations

When a relation models a real situation, its domain and range are cut down to the values that make physical sense: time cannot be negative, and a count of people must be a whole number, so its domain is written with \in W rather than \in\mathbb{R}. These practical restrictions make the domain and range of an applied relation narrower than those of the same equation treated as pure mathematics.
Counted people, tickets, cars: separate dots, \in W
Measured time, distance, height: an unbroken line, \in\mathbb{R}
Example 5

A rental cost with a practical domain

A community league is renting a hall for a fundraiser dinner. The venue charges a setup fee of $350 plus $25 per guest, so C=350+25n gives the total rental cost, in dollars, for n guests. The venue requires at least 50 guests and holds at most 300.

(a) Complete the table of values for n=50,\ 100,\ 150,\ 200,\ 250 and 300 guests.
Substitute each n: 350+25(50)=1\,600, 350+25(100)=2\,850, … , 350+25(300)=7\,850. The costs are in the table above.
(b) Plot the six ordered pairs from part (a) on the grid.
The six points lie on a straight line, since C=350+25n is linear. They are plotted, not joined: only whole numbers of guests are possible.
(c) If all possible ordered pairs from part (b) were plotted, state the domain and range of the relation, and explain why there are restrictions on both.
n counts guests, so it must be a whole number, and the venue sets a minimum of 50 and a maximum of 300:
\boldsymbol{D=\{n\mid 50\le n\le 300,\ n\in W\}}
Each extra guest adds exactly $25, so C climbs in steps of 25 from 350+25(50)=1\,600 to 350+25(300)=7\,850:
\boldsymbol{R=\{1\,600,\ 1\,625,\ 1\,650,\ \dots,\ 7\,850\}}, the multiples of 25 from 1 600 to 7 850.
Both sets are finite (251 values each) but far too long to write out. The domain uses set-builder with \in W; the range is a list with “…” because its values go up by 25, so \{C\mid 1\,600\le C\le 7\,850,\ C\in W\} would wrongly include costs like 1 601.
Both are restricted because this is a real booking: the group size has a practical minimum and maximum and can only be a whole number, and the cost is completely determined by that whole-number guest count.
The ends of the range. The smallest and largest costs come from the smallest and largest numbers of guests. 350+25×50ENTER gives 1 600, and with 300 guests, 7 850. The calculator multiplies first, just like on paper.

Putting it together: which notation?

Every question today came down to the same few decisions. Can the values be listed? If not, what happens at each end, and what kind of number is the variable?

✓

Key ideas

Domain = the inputs used (x); range = the outputs produced (y). From pairs, tables and arrow diagrams: a list, each value once, increasing: D=\{-2,0,2,4,6\}.
On a graph: the domain is the shadow on the x-axis (light from above), the range is the shadow on the y-axis (light from the side). Range: lowest point to highest point.
Ends: solid dot \le,\ \ge; hollow dot <,\ >; arrow: no bound. \{x\mid -3\le x<4,\ x\in\mathbb{R}\}. A whole axis: \{x\mid x\in\mathbb{R}\}.
Real situations: keep only values that make sense. Counts use W (separate dots); measurements use \mathbb{R} (unbroken): \{n\mid 50\le n\le 300,\ n\in W\}.
