Math 10C · Unit 5 Relations and Functions · Lesson 7A

What Is a Function?

Some relations are well behaved: give them an input and you get back exactly one output, every time. Those relations are called functions. Today: how to spot one in every form a relation can take, from a list of ordered pairs to a graph, and the one-second graph check called the vertical line test.

I can…
  • explain what a function is: a relation in which each element of the domain is paired with exactly one element of the range
  • decide whether a relation is a function from its ordered pairs or table (is an input repeated with a different output?) and from its arrow diagram (does any input have two arrows?)
  • use the vertical line test to decide whether a graph is a function, and name two ordered pairs that prove it is not
  • decide from an equation or a description in words whether one input could give two outputs
  • explain why every function is a relation, but not every relation is a function

P(\text{no match})=\frac{365}{365}\cdot\frac{364}{365}\cdots\frac{336}{365}\approx0.294, so P(\text{match})\approx1-0.294=0.706, about 71%.

1

What Is a Function?

Function. A function is a relation in which each element of the domain is paired with exactly one element of the range. If any element of the domain is paired with more than one element of the range, the relation is not a function.

Take the domain D=\{1,8,27,64\} and the range R=\{1,2,3,4\}, joined by two relations. For relation (i) we ask, for each domain element, which range elements divide it evenly; for relation (ii) we ask which range element, when cubed, produces the domain element.

Ask the calculator the question. Is 64 a multiple of 3? 64÷3ENTER gives 21.333…, not a whole number, so no arrow from 64 to 3. Is 64 the cube of 4? 4^3ENTER gives 64, so yes.

The two relations, three ways each

Relation (i): “is a multiple of”
(1,1),\ (8,1),\ (8,2),\ (8,4),\ (27,1),
(27,3),\ (64,1),\ (64,2),\ (64,4)
Relation (ii): “is the cube of”
(1,1),\ (8,2),\ (27,3),\ (64,4)
 

In relation (i) the domain element 8 is paired with three different range elements (1, 2 and 4), so relation (i) is not a function. In relation (ii) every domain element is paired with exactly one range element, so relation (ii) is a function.

Functions are relations

Every function is a relation, but not every relation is a function. A function is a special kind of relation — one in which no input has more than one output. In the diagram, relation (ii) belongs inside the inner oval; relation (i) is a relation but sits outside the “Functions” oval.

Example 1

Reading the function test off three representations

Using the two relations above, explain how you can tell whether a relation is a function by examining each of the following.

(a) the arrow diagram
Look at each element of the domain (left oval). If every domain element has exactly one arrow leaving it, the relation is a function.
In (i) the element 8 has three arrows leaving it (to 1, 2 and 4), so (i) is not a function.
In (ii) every domain element has exactly one arrow leaving it, so (ii) is a function.
(b) the list of ordered pairs
Look at the first coordinates. If any x-value is repeated with two different second coordinates, the relation is not a function.
In (i) the pairs (8,1), (8,2), (8,4) share the first coordinate 8, so (i) is not a function.
In (ii) no first coordinate repeats, so (ii) is a function.
(c) the graph
Apply the vertical line test.
In (i) the vertical line through x=8 passes through the three plotted points (8,1), (8,2), (8,4), so (i) is not a function.
In (ii) every vertical line through a domain value meets exactly one plotted point, so (ii) is a function.
Think Reverse relation (i): send each element of R to the elements of D it divides (“is a factor of”). Is the reversed relation a function?
No. 1 divides all four elements, so it would have four arrows leaving it (to 1, 8, 27 and 64). One input, several outputs.

One test, three pictures

The arrow diagram, the ordered pairs and the graph are three pictures of the same relation, so they must give the same verdict. Each picture shows a repeated input in its own way: two arrows leaving one element, two pairs with the same first coordinate, two dots stacked on one vertical line.

2

The Vertical Line Test

Vertical line test. If every vertical line crosses the graph at most once, the relation is a function. If any vertical line crosses the graph more than once, the relation is not a function. (A vertical line outside the domain misses the graph completely — that is allowed.)

Why vertical? Every point on the vertical line x=1 has first coordinate 1. So the dots that line passes through are all the outputs of the input 1. Two dots on it means one input with two outputs.

!
Horizontal lines don’t matter here. A horizontal line crossing twice means two inputs share one output, like Ben and Cleo sharing July 14. That is allowed for a function. Only a vertical line crossing twice breaks the rule.

(b) From graph C, write two ordered pairs which show that the relation is not a function.
The vertical line x=0 crosses graph C at (0,3) and (0,-3). These two ordered pairs share the same first coordinate but have different second coordinates, so C is not a function.
(c) From graph D, write two ordered pairs which show that the relation is not a function.
The vertical line x=1.6 crosses graph D at (1.6,2) and (1.6,-2), since 0.4(2)^2=1.6 and 0.4(-2)^2=1.6. Same first coordinate, different second coordinates, so D is not a function.
(d) On graphs A and B, imagine a series of vertical lines. Do any of these lines intersect the graph of the relation at more than one point? Explain what this tells you about A and B.
No. On graphs A and B every vertical line drawn through the domain crosses the graph exactly once, as the dashed lines show. By the vertical line test, both A and B are functions.

Recognizing Functions in Different Forms

A relation may be given as a list of ordered pairs, a table, an arrow diagram (mapping diagram), a graph or a description in words. The test is the same in every case: does every element of the domain appear with exactly one output?

Ordered pairs / tableIs an input (first coordinate) repeated with a different output?
Arrow diagramDoes any domain element have two arrows leaving it?
GraphDoes any vertical line cross it twice?
Equation or wordsCould one input give two outputs? Try a value.
!
A repeated output is fine. In (4,4),\ (1,3),\ (6,9),\ (-5,4) the output 4 appears twice, and it is still a function. Only a repeated input with a different output breaks the rule.
Example 3

Six relations in six forms

Determine which of the following relations are functions. Justify each answer.

(a) (7,3),\ (5,7),\ (-2,9),\ (0,3),\ (5,4)
The x-value 5 appears twice, paired with two different outputs, 7 and 4. One input, two outputs: not a function.
(b) (4,4),\ (1,3),\ (6,9),\ (-5,4)
The x-values 4,1,6,-5 are all different. The output 4 repeating does not matter — every input still has only one output: is a function.
(c)
Every domain element (D, E, F) has exactly one arrow leaving it; it does not matter that Y receives two arrows: is a function.
(d)
The plotted points (1,3),(2,1),(4,4),(5,2) all have different x-coordinates, so every vertical line meets the graph at most once: is a function.
(e) The relation pairing each vehicle registered in Alberta with its licence plate number.
Every vehicle registered in Alberta is issued exactly one licence plate number, so each element of the domain corresponds to exactly one element of the range: is a function.
(f)
The vertical line x=0 crosses the closed curve twice (near y\approx1.4 and y\approx-1.7), so it fails the vertical line test: not a function.
Think Swap every pair in (a) to (d), so (x,y) becomes (y,x) and every arrow turns around. Which answers change?
(b) and (c) stop being functions: their repeated output becomes a repeated input ((4,4) and (4,-5); Y sends arrows to E and F). (a) stays not a function (now 3 repeats) and (d) stays a function (its outputs 3,1,4,2 are all different).

Checking Example 3, one form at a time

Six forms, one question each time: can an input have two outputs? Use the check after the class has justified each part.

✓

Key ideas

Function: a relation in which each element of the domain is paired with exactly one element of the range. One input, one output.
Pairs, tables, arrows: not a function if an input is repeated with a different output, or if a domain element has two arrows leaving it. A repeated output is fine.
Graphs: the vertical line test. If any vertical line crosses the graph more than once, it is not a function, and those crossings give two ordered pairs that prove it, like (0,3) and (0,-3).
Every function is a relation, but not every relation is a function. Equations and words: try an input. x=y^2 sends 4 to 2 and -2: not a function.
