Function Notation

In Lesson 7A you decided whether a relation is a function. Once we know it is, we can give it a name, such as f, and a short way to write “the output when the input is x”: f(x). Today: reading, writing and using that notation, forwards (evaluate) and backwards (solve).

I can…
  • read f(4)=13 as “f of 4 is 13”: the name is f, the input is 4, the output is 13 (and it is not f times 4)
  • connect f(x) with y: inputs on the horizontal axis, outputs on the vertical axis, and f(a)=b means the point (a,\ b) is on the graph
  • show a function as a table, an arrow diagram, ordered pairs and a graph, and list its range
  • evaluate f(a) by substituting, using brackets, including an expression into a linear function
  • solve f(x)=b: given the output, find the input
  • Extension use mapping notation, and substitute an expression into a non-linear function

Function Notation

For the function f(x)=3x+1, the output when the input is 4 is

f(4)=3(4)+1=13
We say the image of 4 under f is 13, or that the value of the function is 13 when x=4. The symbol f(x) is read “f of x”: an input x enters the function machine f, and the output is labelled f(x).
xinput
“f”
f(x)output

The same information, written two ways

function notation
equation of the graph
f(x)=3x+1
y=3x+1
f(4)=3(4)+1
y=3(4)+1
f(4)=13
y=13
the point (4,\ 13) is on the graph
The symbol f(x) does double duty: it is a formula for the function f, and it also represents the output value of the function for a particular input x.

Key facts about function notation

  • f(x) does not mean “f times x”: the parentheses indicate an input, not multiplication.
  • The letter in front of the parentheses (here, f) is simply the name of the function; other common names are g, h, P, and so on.
  • Inputs (values of the independent variable, usually x) are plotted on the horizontal axis.
  • Outputs (values of the dependent variable, usually y or f(x)) are plotted on the vertical axis.

Quick check: tap a card to flip it.

Does g(5) mean g\times5?
No. It is the output of g when the input is 5.
In h(t)=2t+7, what is the name? The input variable?
Name h; input variable t.
f(2)=9. Which point is on the graph of f?
(2,\ 9): input on the horizontal axis, output on the vertical.
Is f(x) the independent or the dependent variable?
Dependent: the output depends on the input x.
Math History1673 · 1734

Who first wrote f(x)?

In 1673 the German mathematician Gottfried Leibniz began using the word “function” for lines that do a job in a drawing of a curve. He had no short way to write one.

In 1734 the Swiss mathematician Leonhard Euler (say “OY-ler”) wrote \color{#7b4fc4}f\color{#3d2817}\left(\color{#1f5bd6}\tfrac{x}{a}+c\color{#3d2817}\right) for “a function of \tfrac{x}{a}+c”: f for function, the input in brackets. It is the notation you write today.

Euler’s input was an expression. Let f(x)=3x+1, a=2 and c=1. What is f\left(\tfrac{x}{a}+c\right) when x=8?
The input is \tfrac{8}{2}+1=5, so the output is f(5)=3(5)+1=\boldsymbol{16}.

One Function, Several Representations

A function with a small domain can be shown as a table of values, an arrow diagram, a set of ordered pairs or a graph. Every one of them pairs each input with exactly one output, and the outputs together form the range.

Example 1

Completing a function and showing it three ways

(a) The relation “is the cube of” from Lesson 7A is a function. Written in function notation it is g(x)=\sqrt[3]{x}, with domain \{1,\ 8,\ 27,\ 64\}. Complete:

g(1)=___ g(8)=___ g(27)=___ g(64)=___
g(1)=\sqrt[3]{1}=\boldsymbol{1},   g(8)=\sqrt[3]{8}=\boldsymbol{2},   g(27)=\sqrt[3]{27}=\boldsymbol{3},   g(64)=\sqrt[3]{64}=\boldsymbol{4}

(b) Consider the function f(x)=3x-2, with domain \{-2,\ -1,\ 0,\ 1,\ 2\}.

(i) Complete: f(-2),\ f(-1),\ f(0),\ f(1),\ f(2)
Substitute each domain value into 3x-2:
f(-2)=3(-2)-2=\boldsymbol{-8}, f(-1)=\boldsymbol{-5},
f(0)=\boldsymbol{-2}, f(1)=\boldsymbol{1}, f(2)=\boldsymbol{4}
(ii) List the elements of the range of the function.
Range =\boldsymbol{\{-8,\ -5,\ -2,\ 1,\ 4\}}
(iii) Show the function f as an arrow diagram, a set of ordered pairs, and a graph.
Ordered pairs:
Ordered pairs:
(-2,\ -8),\ (-1,\ -5),
(0,\ -2),\ (1,\ 1),\ (2,\ 4)
Five separate points: the domain has only five numbers, so the dots are not joined.
Think Could a function have f(1)=4 and f(1)=5?
No. The input 1 would have two outputs (two arrows leaving 1), so it would not be a function. Two different inputs with the same output, like h(2)=h(-2)=4 for h(x)=x^2, is fine.

Evaluating and Solving

To evaluate f(a) for a number a, replace every x in the formula for f(x) with a, then simplify. You are given the input: go forwards.
To solve f(x)=b, set the formula equal to b and solve for x. You are given the output and asked for the input: go backwards.

For a linear function the input can also be an expression: if g(x)=5x-2, then g(3t)=5(3t)-2=15t-2.

Evaluating: brackets around the input, every time

Every x in the rule is a slot. Put the input into every slot, in brackets, then follow the order of operations.

!
Brackets around a negative input. For f(x)=x^2+3, f(-3)=(-3)^2+3=9+3=12. Without brackets, -3^2 means -(3^2)=-9, and you get the wrong answer, -6. The calculator does the same thing.
Example 2

Two functions, five values

Consider the functions f(x)=x^2+3 and g(x)=5-x. Evaluate each of the following.

(a) f(4)
f(4)=(4)^2+3
=16+3=\boldsymbol{19}
(b) g(2)
g(2)=5-2=\boldsymbol{3}
(c) f(-3)
f(-3)=(-3)^2+3
=9+3=\boldsymbol{12}
(d) g(-1)
g(-1)=5-(-1)=5+1=\boldsymbol{6}
(e) f(0)-g(0)
f(0)=(0)^2+3=3 and g(0)=5-0=5,
so f(0)-g(0)=3-5=\boldsymbol{-2}
Think Is f(-3) the same as -f(3)?
No. f(-3)=12 (the input is −3), but -f(3)=-(9+3)=-12 (the output of f(3), made negative).
Part (c) on the calculator. Bracket the negative: ((−)3)x²+3ENTER gives 12. Leave the brackets out and the calculator squares only the 3: it gives −6.
Example 3

The same function asked for in three ways

Consider the function f defined by f(x)=4x^3-3x, x\in\mathbb{R}. Determine each of the following.

(a) f(-2)
f(-2)=4(-2)^3-3(-2)
=4(-8)+6=-32+6=\boldsymbol{-26}
(b) the value of f when x=3
f(3)=4(3)^3-3(3)
=4(27)-9=108-9=\boldsymbol{99}
(c) the image of 5 under f
f(5)=4(5)^3-3(5)
=500-15=\boldsymbol{485}
Check (c) and (a). 4×5^3−3×5ENTER gives 485. For (a), put (-2) in brackets in both places.
Example 4

Substituting into a linear function

Consider the linear function g(x)=5x-2.

(a) an expression for g(a)
Replace x with a: g(a)=\boldsymbol{5a-2}
(b) an expression for g(3t)
g(3t)=5(3t)-2=\boldsymbol{15t-2}
(c) an expression for g(a+1)
g(a+1)=5(a+1)-2
=5a+5-2=\boldsymbol{5a+3}
(d) Solve g(x)=18.
5x-2=18
5x=20
x=\boldsymbol{4}

An expression as the input (Example 4 check)

An expression goes into the slot exactly like a number: whole, and in brackets. Then check your answer by putting a number in for the letter: both forms must agree.

Forwards and backwards on the graph

On the graph of y=f(x), evaluating f(a) starts on the horizontal axis: up to the graph, across to the output. Solving f(x)=b starts on the vertical axis: across to the graph, down to the input. A slanted line is met once; a curve can be met more than once.

Example 5

Going backwards: solving f(x)=k

Consider the function f(x)=x^2-7, x\in\mathbb{R}.

(a) Evaluate f(5).
f(5)=(5)^2-7
=25-7=\boldsymbol{18}
(b) Solve the equation f(x)=29.
x^2-7=29
x^2=36
x=\pm\sqrt{36}=\boldsymbol{\pm6}
(c) Solve f(t)=38, where t>0. Give your answer in simplest radical form.
t^2-7=38
t^2=45
t=\pm\sqrt{45}=\pm\sqrt{9\cdot5}=\pm3\sqrt5
Since t>0, t=\boldsymbol{3\sqrt5}
Think Why does f(x)=29 have two answers, while g(x)=18 in Example 4 had only one?
Undoing a square gives two numbers: 6^2 and (-6)^2 are both 36 (two inputs, one output, still a function). A linear function with a non-zero slope, like g, never gives two inputs the same output, so going backwards gives exactly one answer.
Is \sqrt{45} really 3\sqrt5? Both decimals should match: √45ENTER and 3×√5ENTER both give 6.708203932. (The radical form is the exact answer.)

To find f(3x) or f(x+2), replace every x in the formula with the entire expression, in parentheses, then simplify.

Key ideas

Read it: f(4)=13 is “f of 4 is 13”: name f, input 4, output 13. It is not f times 4. The point (4,\ 13) is on the graph.
Represent it: a table, an arrow diagram, ordered pairs, a graph. Inputs (independent) go on the horizontal axis, outputs (dependent) on the vertical. The outputs form the range.
Evaluate = forwards: put the input into every x, in brackets: f(-3)=(-3)^2+3=12; g(a+1)=5(a+1)-2=5a+3.
Solve = backwards: you know the output. Set the formula equal to it and solve: 5x-2=18 gives x=4. A square can give two answers: x^2-7=29 gives x=\pm6.
