Variables, Domain, and Range

A variable is discrete if it can take only separate, countable values, such as a number of items. It is continuous if it can take any value within an interval, such as a measurement of time, length or volume.
The domain of a relation is the set of values taken by the independent variable: the inputs, the first coordinates, plotted on the horizontal axis. The range is the set of values taken by the dependent variable: the outputs, the second coordinates, plotted on the vertical axis.

How the answer is written

A relation with finitely many values gets a list inside braces, each value written once and in increasing order, e.g. D=\{2,5,9\}. A relation with infinitely many values gets set-builder notation, e.g. R=\{y\mid y\ge-3,\ y\in\mathbb{R}\} (here R names the range and \mathbb{R} the real numbers). A set unbounded in both directions is written \{x\mid x\in\mathbb{R}\}. For a count, use W (whole numbers), or I with a lower bound such as n\ge0, in place of \mathbb{R}.

Example 1

Discrete or continuous

Classify each variable as discrete or continuous.

(a) The number of students in a classroom.
A classroom holds a whole number of students; there is no such thing as 23.4 students. Only separate, countable values: discrete.
(b) The time taken to swim 100 metres.
A stopwatch reading can be any value in an interval: 61.34 s, 61.341 s, and so on. Continuous.
(c) The volume of water in a tank.
Volume can take any value in a range, such as 14.7 L. Continuous.
(d) The number of pages in a book.
A book has a whole number of pages, so only separate, countable values occur: discrete.

Inputs across, outputs up

Every ordered pair (x,\ y) is an input and its output. The input is the independent variable (the cause); the output is the dependent variable (the effect, which depends on the input).

Example 2

Finding the false statement

Exactly one of the following statements is false. Identify it and explain why.

(a) The domain of a relation is the set of values taken by the independent variable.
(b) The independent variable is represented by the second coordinate of each ordered pair.
(c) On a Cartesian plane, the outputs of a relation are graphed on the vertical axis.
(d) The range of a relation is the set of values taken by the dependent variable.
Statement (b) is false. In an ordered pair (x,\ y) the first coordinate x is the independent variable (the input) and the second coordinate y is the dependent variable (the output). Statement (b) reverses this.
(a), (c) and (d) are all correct: the domain is the set of independent-variable values, outputs are graphed vertically, and the range is the set of dependent-variable values.

Domain and range are the graph’s shadows

Squash the graph straight down onto the x-axis: the shadow is the domain. Squash it sideways onto the y-axis: the shadow is the range. A closed dot is included, an open dot is not, and an arrow keeps going forever.

Example 3

Domain and range from a graph

The graphs of two relations, P and Q, are shown below. Both curves continue forever in the directions of the arrows. State the domain and range of each relation, then say whether the two domains are the same or different, and whether the two ranges are the same or different.

(a) Relation P: domain and range.
The curve opens to the right from its leftmost point at x=-2, and continues up and down forever.
D=\{x\mid x\ge-2,\ x\in\mathbb{R}\}
R=\{y\mid y\in\mathbb{R}\}
(b) Relation Q: domain and range.
The curve opens upward from its lowest point (0,\ -1), and continues left and right forever.
D=\{x\mid x\in\mathbb{R}\}
R=\{y\mid y\ge-1,\ y\in\mathbb{R}\}
(c) Same or different?
P’s domain is restricted; Q’s is all real numbers: the domains are different.
P’s range is all real numbers; Q’s is restricted: the ranges are different as well.

Intercepts of a Relation

An x-intercept is the value of x where the graph meets (crosses or touches) the x-axis: substitute y=0 and solve for x.
A y-intercept is the value of y where the graph meets the y-axis: substitute x=0 and solve for y.

As in Lesson 3, the intercept is the value and the intercept point is the ordered pair. A relation may have several x-intercepts, but a function has at most one y-intercept, since one input cannot give two outputs.

To the nearest hundredth. Leave the fraction until the end, then divide once. 10÷3= shows 3.333333333; the third decimal is 3, so round down to 3.33.
Example 4

An intercept to the nearest hundredth

To the nearest hundredth, determine the x-intercept of the graph of the line 3x+7y-10=0.
Substitute y=0: 3x+7(0)-10=0, so 3x=10 and x=\dfrac{10}{3}=3.333\ldots
The x-intercept is 3.33 to the nearest hundredth (intercept point (3.33,\ 0)).
Example 5

Combining both kinds of intercept

The graph of the relation 5x^2-4y=20 has x-intercepts a and b, and y-intercept c. Determine the value of the product abc.
x-intercepts, y=0: 5x^2-4(0)=20\Rightarrow x^2=4\Rightarrow x=\pm2, so a and b are 2 and -2.
y-intercept, x=0: 5(0)^2-4y=20\Rightarrow -4y=20\Rightarrow y=-5, so c=-5.
abc=(2)(-2)(-5)=(-4)(-5)=\boldsymbol{20}

Functions in Context

A relation is a function only when every input produces exactly one output. On a graph this is checked with the vertical line test: if every vertical line crosses the graph at most once, the relation is a function; if any vertical line crosses it more than once, it is not.
Function notation f(x), read “f of x”, names the output that the function f produces from the input x; it does not mean f times x. To evaluate f(a), replace every x in the rule for f with a and simplify.
!
Brackets around a negative input. f(-3)=2(-3)^2-5=2(9)-5=13. Without brackets, -3^2 means -(3^2)=-9, and the answer comes out -23. On the calculator use (−) inside brackets.

A model in context: forwards, then its domain and range

A real-world model is a function too. Use it forwards by substituting the input; read a sensible domain and range from what the variables mean.

Example 6

A cost model, forwards and as a domain and range

The cost, in dollars, of publishing a school newsletter is partly fixed and partly depends on the number n of copies printed: C=150+0.08n.

(a) Determine the cost of publishing 685 newsletters.
Substitute n=685:
C=150+0.08(685)=150+54.80=\boldsymbol{204.80}
The cost of publishing 685 newsletters is $204.80.
(b) The domain of this relation can be written in the form n\ge a and the range in the form C\ge b. State the values of a and b.
Record the value of b.
The number of copies cannot be negative, so the smallest n is 0: \boldsymbol{a=0}.
Cost is least when n=0: C=150+0.08(0)=150, so \boldsymbol{b=150}.
Domain n\ge0, range C\ge150.
Example 7

Evaluating over a finite domain

The function f(x)=2x^2-5 has domain \{-5,-3,0,1,4\}. Evaluate f at each value.

(a) f(-5)=
2(-5)^2-5=2(25)-5
=50-5=\boldsymbol{45}
(b) f(-3)=
2(-3)^2-5=2(9)-5
=18-5=\boldsymbol{13}
(c) f(0)=
2(0)^2-5=0-5
=\boldsymbol{-5}
(d) f(1)=
2(1)^2-5=2-5
=\boldsymbol{-3}
(e) f(4)=
2(4)^2-5=2(16)-5
=32-5=\boldsymbol{27}
(f) State the range of the function.
A finite domain gives a finite range: each output once, in increasing order.
R=\{-5,-3,13,27,45\}

Reading function values off a graph

f(a) is the height of the graph above (or below) x=a: go to a on the x-axis, up or down to the graph, then across to the y-axis. Solving f(x)=b runs the same path backwards.

Example 8

Reading function values off a graph

The diagram shows the graph of the function y=f(x). The function is defined only at the six inputs shown, so the graph is six separate dots, not joined. Use the graph to state the value of f(-2)+f(2).
The dot directly above x=-2 sits at y=3, so f(-2)=3.
The dot directly below x=2 sits at y=-5, so f(2)=-5.
f(-2)+f(2)=3+(-5)=\boldsymbol{-2}

Working with Linear Functions

A linear function can be used forwards, by substituting a given input to get the output, or backwards, by setting the function equal to a given output and solving the resulting equation for the input. The graph of a linear function such as Q(x)=6x+5 is a straight (non-vertical) line, so it always passes the vertical line test.
Example 9

Forwards and backwards through a linear function

Consider the function Q(x)=6x+5.

(a) Determine the value of Q(4).
Substitute x=4:
Q(4)=6(4)+5=24+5=\boldsymbol{29}
(b) If Q(b)=2, determine the value of b.
The output is given, so set Q(b)=2 and solve for the input:
6b+5=2
6b=-3
b=-\dfrac{3}{6}=\boldsymbol{-\dfrac{1}{2}}

The vertical line test

Sweep a vertical line across the graph. If it ever crosses twice, one input has two outputs, so the relation is not a function.

Example 10

The vertical line test

Which of the diagrams below shows a relation that is not a function? Justify your answer using the vertical line test.
In A (a downward parabola), B (a horizontal line) and D (a V-shape), every vertical line meets the graph at most once: all three are functions.
Graph C is a circle. A vertical line through its middle meets it twice, so one x-value is paired with two different y-values. Diagram C is not a function.

Key ideas

Counted or measured? Counted values are discrete (dots); measured values are continuous (a line). Few values: a list \{-5,-3,13\}, once each, in order. Infinitely many: \{x\mid x\ge-2,\ x\in\mathbb{R}\}.
Shadows: the domain is the graph’s shadow on the x-axis (inputs, independent, first coordinates); the range is its shadow on the y-axis (outputs, dependent, second coordinates).
Intercepts: y=0 gives the x-intercepts; x=0 gives the y-intercept. A function has at most one y-intercept.
Functions: one output per input; the vertical line test. f(a) forwards: substitute. f(x)=b backwards: solve. On a graph, f(a) is the height above x=a.
