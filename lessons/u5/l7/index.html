Function Notation: Graphs, Conversions, and Real-World Models

A function can be written two ways, f(x)=2x-3 or y=2x-3, and they say exactly the same thing. Today we switch between them, read a graph forwards (input given, find the output) and backwards (output given, find every input), and make function models tell a real story: a draining pool, a factory’s costs, a model rocket. We also find where each story stops.

I can…
  • convert between function notation f(x)=\ldots and x-y notation y=\ldots, keeping the same input variable
  • graph a function from a table of values
  • read f(a) from a graph (up or down, then across) and solve f(x)=b (across, then up or down), counting every solution
  • write ordered pairs, intercepts, domain and range of a graph using function notation
  • evaluate and interpret a function model in context, with units, and choose a sensible domain and range for it

1

Function Notation and x-y Notation

Every function written with y can also be written in function notation, and the reverse: the two forms describe the same rule. In f(x)=2x-3 the input values (values of x) form the domain and the output values (values of f(x)) form the range, so f(x) plays exactly the role y plays.

Function notation
x-y notation
f(x)=2x-3
y=2x-3
To go from function notation to x-y notation, replace the function name and its brackets (such as f(x)) with y. To go the other way, replace y with a function name and brackets. The independent variable never changes: h(t)=t^2+3t-8 becomes y=t^2+3t-8.
Independent variable (the input): its values make up the domain, shown on the horizontal axis.
Dependent variable (the output): its values make up the range, shown on the vertical axis.

ii) h(t)=t^2+3t-8
Replace h(t) with y; the input variable stays t: \boldsymbol{y=t^2+3t-8}
(b) Express the relation y=9x-4 in function notation.
Replace y with a function name and brackets: \boldsymbol{f(x)=9x-4}
(c) The graph of the function defined by y=f(x) has equation y=7-2x. Express the equation in function notation.

Graphing a Function

Once a function is written in x-y notation it is graphed like any other equation in two variables: choose input values, compute the matching output values, plot the ordered pairs, and join them. Think of the function as a machine: an input goes in, the rule works on it, one output comes out.

Example 2

From a table of values to a graph

Use a table of values (or a graphing calculator) to sketch the graph of the function f(x)=2x-3.

Choose inputs and compute outputs, e.g. f(-2)=2(-2)-3=-7 and f(3)=2(3)-3=3:
Plot (-2,-7), (-1,-5), (0,-3), (1,-1), (2,1), (3,3) and join them: the points lie on a straight line, as the graph of every linear function does.
3

Reading Values from the Graph of a Function

Every question about inputs, outputs, ordered pairs, domain and range can be answered from the picture. Two opposite readings are needed, and they must not be confused.

Forwards: f(3) gives the input x=3 and asks for the output. Move along the horizontal axis to 3, then read up or down to the graph (and across to the vertical axis). There is exactly one answer.
Backwards: f(x)=3 gives the output 3 and asks for the input. Move along the vertical axis to 3, then read across to the graph (and down or up to the horizontal axis). There may be one answer, several, or none: count every point of the graph at that height.

Why forwards has one answer but backwards can have many

A function passes the vertical line test, so a vertical line (an input) meets the graph at most once. A horizontal line (an output) has no such rule.

The domain is the span of the graph along the horizontal axis; the range is its span along the vertical axis. An x-intercept is a point where the output is 0, so it is written f(a)=0; the y-intercept is the output at x=0, written f(0).
!
f(3) and f(x)=3 are different questions. In f(3) the 3 is an input (start on the horizontal axis). In f(x)=3 the 3 is an output (start on the vertical axis).

4

Replacing an Equation with Function Notation

A scenario described by an equation such as h=-2t+12, where h is the height of a candle, in cm, after t hours, is a function: every value of t produces exactly one value of h. Renaming the output variable to show its dependence on the input gives

h(t)=-2t+12.

Nothing about the rule has changed, only how it is written. The expression h(t) is read “h of t” and means the output produced by h when the input is t, so h(4) is a compact way of asking for the height of the candle after 4 hours.

Reading function notation. In a statement f(a)=b, a is the input (independent variable) and b is the output (dependent variable) that results from it. To evaluate f(a), substitute a for the input variable everywhere it appears in the rule, then simplify. To interpret f(a)=b in words, describe both the input and the output in the context of the problem, units and all.
5

Domain, Range, and the Limits of a Model

A rule such as h(t)=-2t+12 is defined for every real number t, but in a real-world scenario only some inputs make sense: a candle cannot have a negative height and time cannot run backward. The domain and range of the real-world function are therefore usually restricted to a smaller interval than the bare rule allows. Identifying where a model stops describing the physical situation (for instance once the candle has completely melted) matters as much as evaluating it correctly.

Example 4

Draining a pool

A community pool is being drained for the winter. The volume of water remaining is modelled by V(t)=-450t+9\,000, where V(t) is the volume of water, in litres, remaining in the pool t minutes after draining begins.

(a) Sketch the graph of the function on the grid provided.
The volume starts at 9\,000 L and drops 450 L every minute. The model stops at t=20, when the pool is empty.
(b) Determine the value of V(6).
V(6)=-450(6)+9\,000=-2\,700+9\,000=\boldsymbol{6\,300}
(c) Write in words the meaning of V(6).
Six minutes after draining begins, 6\,300 litres of water remain in the pool.

(d) Evaluate the following, and explain the significance of each.

i) V(0)
V(0)=-450(0)+9\,000=9\,000. The pool held 9\,000 L before draining began: the initial volume.
ii) V(15)
V(15)=-6\,750+9\,000=2\,250. After 15 minutes, 2\,250 L remain in the pool.
iii) V(22)
V(22)=-9\,900+9\,000=-900. A negative volume is impossible. The pool is already empty at t=20 (V(20)=0) and stays empty, so the rule no longer describes the pool.
(e) How long will it take for the volume to drop to 1\,350 litres?
-450t+9\,000=1\,350
-450t=-7\,650
t=\boldsymbol{17} minutes
(f) Suggest an appropriate domain and range for the function.
Draining runs from t=0 (full, 9\,000 L) to t=9\,000\div450=20 min (empty, 0 L).
\{t\mid 0\le t\le 20,\ t\in\mathbb{R}\}
\{V(t)\mid 0\le V(t)\le 9\,000,\ V(t)\in\mathbb{R}\}
Evaluating on the TI-30XIIS. Type the rule with the input in place of t. Use (−) for the negative: (−)450×6+9000ENTER gives V(6). For (e), undo the rule: subtract 9 000, then divide by −450.
Example 5

Cost of production

Bright Spark Electronics manufactures wireless earbuds. The cost of production is modelled by C(n)=18\,400+27n, where C(n) is the cost, in dollars, of producing n pairs of earbuds.

(a) Sketch the graph of the function for a maximum of 5\,000 pairs.
The cost starts at \$18\,400 and rises \$27 for each pair: the line runs from (0,\ 18\,400) to (5\,000,\ 153\,400).
(b) Determine the value of C(120).
C(120)=18\,400+27(120)=18\,400+3\,240=\boldsymbol{21\,640}
(c) Write in words the meaning of C(120).
It costs \$21\,640 to produce 120 pairs of earbuds.
(d) Evaluate C(0) and explain its significance.
C(0)=18\,400+27(0)=18\,400. This is the fixed cost (equipment, facility) that the company pays before producing a single pair.
(e) How many pairs of earbuds can be produced for \$29\,200?
18\,400+27n=29\,200
27n=10\,800
n=\boldsymbol{400} pairs
Check (b) and (e) on the TI-30XIIS. 18400+27×120ENTER. The calculator multiplies first, just like the order of operations.
i
Dots or a line? n counts pairs of earbuds, so strictly only whole numbers make sense: the graph is really 5 001 separate dots. They are so close together that we draw them as a line.
Example 6

A model rocket

A model rocket is launched straight up from the ground. Its height is modelled by h(t)=-20t^2+1\,600t, where h(t) is the height, in cm, of the rocket t seconds after launch.

(a) Sketch the graph of the function on the grid provided.
A parabola opening down through (0,\ 0) and (80,\ 0), peaking at t=40 s, h=32\,000 cm.
(b) Determine the values of h(20) and h(60).
h(20)=-20(400)+1\,600(20)=-8\,000+32\,000=24\,000
h(60)=-20(3\,600)+1\,600(60)=-72\,000+96\,000=24\,000
(c) Does h(20)=h(60)? Do they mean the same thing? Explain.
Yes, both equal 24\,000 cm, but they do not mean the same thing. The rocket passes that height twice: at t=20 s while rising, and at t=60 s while falling. The flight is symmetric about its peak at t=40 s.

(d) Evaluate the following, and explain their significance in the context of the question.

i) h(0)
h(0)=0. The rocket is at ground level at the moment of launch.
ii) h(80)
h(80)=-128\,000+128\,000=0. The rocket is back on the ground: it lands 80 s after launch.
iii) h(90)
h(90)=-162\,000+144\,000=-18\,000. A negative height is impossible: the rocket landed at t=80 s and does not continue below ground, so the rule no longer applies.
(e) What is the highest point the rocket will reach?
The flight is symmetric and h(20)=h(60), so the peak is halfway between, at t=40 s:
h(40)=-32\,000+64\,000=\boldsymbol{32\,000} cm
(f) When will the rocket land?
Land when h(t)=0:
-20t^2+1\,600t=0
-20t(t-80)=0
t=0 (launch) or t=\boldsymbol{80} s
(g) Suggest an appropriate domain and range for h(t).
\{t\mid 0\le t\le 80,\ t\in\mathbb{R}\}
\{h(t)\mid 0\le h(t)\le 32\,000,\ h(t)\in\mathbb{R}\}
Square only the input. For h(20): (−)20×20x²+1600×20ENTER. The x² squares just the 20 before it, so the −20 is not squared.
!
The rule doesn’t know the story. h(90) and V(22) both give numbers, but negative heights and volumes are impossible. Always ask whether an input makes sense before trusting the output.
✓

Key ideas

Two notations, one rule: f(x)=2x-3 and y=2x-3. Swap f(x) and y; the input variable never changes: h(t)=t^2+3t-8 becomes y=t^2+3t-8.
Forwards, f(a): input given. Start on the horizontal axis, go up or down to the graph, then across. Exactly one answer.
Backwards, f(x)=b: output given. Start on the vertical axis, go across, then up or down. Zero, one or several answers: count every crossing. Intercepts: f(a)=0 and f(0).
Models: say f(a)=b in words with units (input, then output). Restrict the domain and range to what makes sense: V(22)=-900 L is impossible.
