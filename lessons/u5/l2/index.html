Describing Relationships Between Two Quantities

A relation compares two quantities that change together. One relation can be shown six ways: in words, as a table of values, as ordered pairs, as an arrow diagram, as an equation and as a graph. Behind all six is the same question: which quantity depends on the other?

I can…
  • describe a relation in words, with a table of values, a set of ordered pairs, an arrow diagram, an equation and a graph
  • identify the independent variable (input) and the dependent variable (output) in each of those six representations
  • list the inputs and the outputs of a relation
  • build a table of values and a graph from an equation, and read the graph forwards (y from x) and backwards (x from y)
  • tell a linear relation from a nonlinear one by its graph, its equation or its table
RF1 Interpret and explain the relationships among data, graphs and situations.
RF2 Demonstrate an understanding of relations and functions.

Temperature and ice cream sales: which one depends on the other?
Ice cream sales depend on temperature. Hot days sell more cones, but selling cones doesn’t heat up the day.
2
Minutes charging and battery level: which one do you control?
You control the minutes charging. The battery level is the result.
3
Graphing the charging data, which quantity goes on the horizontal axis?
Minutes charging on the horizontal axis; battery level on the vertical axis.
!
The big one. In the beach town, ice cream sales and shark attacks rise and fall together. So… Guess first.
A Ice cream causes shark attacks.
B Shark attacks sell ice cream.
C Neither: something else drives both.
D Pure coincidence.
C, neither. The hidden variable is hot weather (summer). Heat brings crowds to the beach: more people buy ice cream, and more people are in the water where the sharks are. Both quantities depend on the temperature, not on each other (watch the graph).
A and B are the classic trap: “they rise together, so one must cause the other.” Rising together is correlation, not causation. D is tempting, but there is a real reason they match, just not a direct one. (The graph uses made-up data.)
Today’s lesson: the quantity that depends on the other is the dependent variable; the one it depends on is the independent variable.
+
Early finishers. In a K–12 school, students with bigger shoes read at higher levels. Should the school buy everyone bigger shoes?
No. The hidden variable is age: older students have bigger feet and read at higher levels.

Relations and Their Six Representations

A comparison between two sets of elements is called a relation.

The fuel remaining in a lawn mower’s tank is related to how long it has been running; the monthly cost of a streaming service is related to the number of screens it allows; the resale value of a bicycle is related to its age. Throughout this unit a relation is described in six ways:

“…”in words
a table of values
(x,\ y)a set of ordered pairs
an arrow diagram (mapping diagram)
y=\dotsan equation
a graph

2

Investigating a Relation

Consider the relation “the fuel consumption rate, F (litres per 100 km), of a delivery van is related to its speed, s (km/h).”

Fuel consumption depends on speed, so F is the dependent variable and s is the independent variable. Values of the independent variable are the inputs; values of the dependent variable are the outputs.

To decide which is which, test the sentence both ways: “A depends on B” and “B depends on A”. Only one of them makes sense. The quantity you choose or control is the input; the one that responds is the output.

The van’s test data

Test data collected at 20,\ 40,\ 60,\ \dots,\ 140 km/h gives the table and graph below.

Ordered pairs (s,\ F): (20,\ 13.2),\ (40,\ 9.2),\ (60,\ 6.8),\ (80,\ 6.0),\ (100,\ 6.8),\ (120,\ 9.2),\ (140,\ 13.2).

An output exists for every speed between the smallest and largest tested, not just the seven chosen, so the plotted points are joined with a smooth curve. An equation that closely fits the data is

F=0.002s^2-0.32s+18.8
The equation is only meaningful for the speeds that make up the domain of the relation: it would not make sense to use it for, say, s=-40. The set of all output values is the range of the relation.
A speed that wasn’t tested: s=50. Substitute into the equation: 0.002×50x²−0.32×50+18.8ENTER gives 7.8 L/100 km, right on the curve.

Locating the Independent and Dependent Variable

Ordered pairthe first coordinate is a value of the independent variable; the second is a value of the dependent variable.
Table of valuesthe independent variable is listed first: to the left of, or above, the dependent variable.
Arrow diagramarrows point from the independent variable to the dependent variable.
Graphthe independent variable is on the horizontal axis; the dependent variable is on the vertical axis.
Equationwhen the equation is solved for one variable, that variable is usually the dependent one, but the context decides. (An equation such as 4x-3y+24=0 is not solved for either variable.)
\overbrace{\textcolor{#7b4fc4}{y}}^{\substack{\text{dependent variable}\\ \text{(the output)}}}\;=\;\underbrace{-2\textcolor{#c27a0e}{x}+9}_{\substack{\text{independent variable } x \text{ sits}\\ \text{inside this expression (the input)}}}
!
It isn’t always x and y. Any letters can name the variables. Don’t go by the letter: go by the position (first coordinate, left column, horizontal axis, start of the arrows) or, in words, by which quantity depends on the other.

4

From an Equation to a Table and a Graph

An equation is a recipe for outputs: substitute each input to get its output. Each row of the table is an ordered pair, and each pair is a point. Once the graph is drawn it can be read both ways: forwards (go up from an x-value to the graph, then across to read y) and backwards (go across from a y-value to the graph, then down to read x).

Squaring a negative input? Brackets! For y=x^2-8 at x=-5: ((−)5)x²−8ENTER gives 25-8=17. Without the brackets the calculator squares only the 5 and then makes it negative: -25-8=-33.

(c) Use the symmetry of the graph or table to predict the value of y when x=-4.
The table is symmetric about x=0 (x=\pm1\to y=-7, \pm2\to-4, \pm3\to1), so x=-4 gives the same output as x=4: \boldsymbol{y=8}.

(f) Why do you think this type of relation is called a nonlinear relation?
Its graph is a curve, not a straight line: the x^2 term means equal steps in x do not produce equal steps in y.
Think x=3 and x=-3 both give the output 1. Can two inputs share an output? Can one input have two outputs here?
Two inputs can share an output (like 13 in Example 1(a)). But each input here has only one output: squaring a number gives one answer. (Lesson 7 makes this idea official.)

Linear or nonlinear? Three ways to tell

The table test for linearity. When the inputs in a table go up in equal steps, look at how the outputs change from one row to the next. If the outputs change by the same amount every step (a constant difference), the relation is linear. If they do not, it is nonlinear.

In Example 3 (x=-2,\ -1,\ 0,\ 1,\ 2) the outputs -10,\ -7,\ -4,\ -1,\ 2 go up by 3 every step: linear. In Example 4 (x=0,\ 1,\ 2,\ 3,\ 4) the outputs -8,\ -7,\ -4,\ 1,\ 8 go up by 1,\ 3,\ 5,\ 7: nonlinear.

!
Equal steps in the inputs first. If the inputs jump unevenly (say 0,\ 1,\ 3,\ 4), the output changes can look uneven even for a straight line. Check the input column before you judge the output column.
Grapha straight line → linear; a curve → nonlinear.
Tableequal input steps give equal output changes → linear.
Equationthe input only to the first power (no x^2) → linear.
✓

Key ideas

A relation compares two quantities. Six views of one relation: words, a table of values, ordered pairs, an arrow diagram, an equation and a graph.
The dependent variable (output) depends on the independent variable (input). Test the sentence both ways: only one makes sense.
Where is the independent variable? First coordinate · left column (or top row) · start of the arrows · horizontal axis. An equation is usually solved for the dependent variable.
Linear: a straight-line graph; equal input steps give equal output changes; no x^2. Nonlinear: a curve, like y=x^2-8.
