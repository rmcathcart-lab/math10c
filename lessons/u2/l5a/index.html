Rational Exponents and Radicals

What could 7^{1/2} or 27^{2/3} possibly mean? If the exponent laws still work for fractions, there is only one answer: a fraction exponent is a root. Today we find out why, evaluate powers like these without a calculator, and switch back and forth between powers and radicals.

I can…
  • explain, using the exponent laws, why a^{1/n}=\sqrt[n]{a}
  • evaluate a^{m/n} and a^{-m/n} without a calculator, taking the root first
  • decide when a power with a negative base is a real number, and where its minus sign belongs
  • convert a power with a rational exponent to a radical, and a radical to a power
  • use rational exponents and a calculator to solve problems, like the edge of a cube of known volume
AN3 Demonstrate an understanding of powers with integral and rational exponents.

1

What Does a^{1/n} Mean?

The exponent laws were built for whole-number exponents, but they ought to work for a fraction too, and that forces a meaning on a^{1/2}. Multiply 7^{1/2} by itself, using the product law:

7^{1/2}\times7^{1/2}=7^{\frac12+\frac12}=7^{1}=7

But \sqrt{7}\times\sqrt{7}=7 too. Both numbers give 7 when multiplied by themselves, so they’re the same number: 7^{1/2}=\sqrt{7}. Three equal factors work the same way: 2^{1/3}\times2^{1/3}\times2^{1/3}=2^1=2, so 2^{1/3}=\sqrt[3]{2}.

The nth root as a power (for a natural number n\ge2)
a^{1/n}=\sqrt[n]{a}
If n is even, a must be non-negative (a\ge0) for a real root. If n is odd, a can be any real number.
♪
Back to the piano. Twelve equal steps make r^{12}=2, so r=2^{1/12}=\sqrt[12]{2}\approx1.0595. Every key is 440\times2^{k/12} Hz, where k is its number of steps up.
2

Extending to a^{m/n}

The denominator of a rational exponent tells which root to take. The numerator is an ordinary power, applied before or after the root.

numerator m
the power
a^{\textcolor{#c27a0e}{m}/\textcolor{#13807a}{n}}=\left(\sqrt[\textcolor{#13807a}{n}]{a}\right)^{\textcolor{#c27a0e}{m}}=\sqrt[\textcolor{#13807a}{n}]{a^{\textcolor{#c27a0e}{m}}}
denominator n
the index of the root
Roots grow at the bottom: the root is in the denominator.

Both orders give the same answer for 27^{2/3}, but one is much easier:

Rational exponents (natural numbers m and n\ge2, with \tfrac{m}{n} in lowest terms)
a^{m/n}=\left(\sqrt[n]{a}\right)^m=\sqrt[n]{a^{m}}
If n is even, a must be non-negative. Root first keeps the numbers small.
3

Negative Rational Exponents

A negative exponent still means take the reciprocal, a^{-k}=\dfrac{1}{a^k}, whether or not the exponent is a fraction: 27^{-2/3}=\dfrac{1}{27^{2/3}}=\dfrac{1}{9}.

Negative rational exponents (\tfrac{m}{n} in lowest terms, a\ne0)
a^{-m/n}=\dfrac{1}{a^{m/n}}=\dfrac{1}{\left(\sqrt[n]{a}\right)^m}=\dfrac{1}{\sqrt[n]{a^{m}}}
If n is even, a must be positive.

Think of any rational exponent as three jobs, done in order: the sign flips, the denominator roots, the numerator powers.

!
A negative exponent never makes the answer negative. 27^{-2/3}=\tfrac19, not -9. The minus sign in the exponent means flip.

When is a^{m/n} a real number?

Index n odd (3, 5, 7, …)
Any base works, even a negative one: (-2)^3=-8, so (-8)^{1/3}=-2. (a\ne0 if the exponent is negative.)
Index n even (2, 4, 6, …)
The base must be \ge0 (>0 if the exponent is negative). No real number to an even power is negative, so (-16)^{1/4} isn’t real.
Reduce the exponent first. (-8)^{2/6} must be treated as (-8)^{1/3}=-2. Squaring first, \sqrt[6]{(-8)^2}=\sqrt[6]{64}=2, gives the wrong sign.
4

Evaluating Rational-Exponent Powers

1Negative exponent? Flip the base.
2Denominator: take that root first.
3Numerator: raise to that power.
4Brackets in the base? Work them out first.
Brackets around a fraction exponent. 8^(2÷3)ENTER gives 4. Leave out the brackets and the calculator does 8^2\div3=\tfrac{64}{3}\approx21.33: powers come before division.
The \sqrt[x]{\ } key takes any root. Type the index first: 32nd^64ENTER gives \sqrt[3]{64}=4.
Example 1

Evaluating numerical powers without a calculator

Evaluate each power without using a calculator.

(a) 16^{3/2}
Root first, then power:
\left(\sqrt{16}\right)^3=4^3=\mathbf{64}
(b) 1\,000^{2/3}
\left(\sqrt[3]{1\,000}\right)^2=10^2
=\mathbf{100}
(c) 8^{-4/3}
Negative ⇒ reciprocal:
\dfrac{1}{\left(\sqrt[3]{8}\right)^4}=\dfrac{1}{2^4}=\mathbf{\dfrac{1}{16}}
(d) \left(5^2+12^2\right)^{1/2}
Brackets first: 25+144=169
169^{1/2}=\sqrt{169}=\mathbf{13}
Think Mo did (d) as 5+12=17. Why is that wrong?
An exponent doesn’t split over +: \left(5^2+12^2\right)^{1/2}=\sqrt{169}=13, not 5+12. (It’s the hypotenuse of a 5-12-13 triangle!)

Negative bases: where is the minus sign?

(-27)^{2/3}: the brackets make -27 the base. The minus goes into the root.
-27^{2/3}: the exponent belongs to 27 only. The minus waits outside: -\left(27^{2/3}\right).
Brackets for a negative base, and use (−), not subtract. ((−)27)^(2÷3) gives 9. Without the first brackets the calculator does the power first, then the negative: −9, which is -27^{2/3}. Try (-16)^{1/4} too.
Example 2

Negative bases and the placement of the minus sign

(a) Evaluate (-27)^{2/3}.
Index 3 is odd, so the cube root of a negative exists:
\left(\sqrt[3]{-27}\right)^2=(-3)^2=\mathbf{9}
(b) Evaluate -\left(27^{2/3}\right).
The minus is outside: evaluate, then negate.
27^{2/3}=\left(\sqrt[3]{27}\right)^2=9, so the answer is \mathbf{-9}
(c) Exactly one of these powers has no meaning (as a real number). Which one? Explain why the other three can be evaluated.
A. 27^{2/3}B. (-27)^{2/3}C. 16^{3/2}D. (-16)^{3/2}
A =9 (positive base). B =9 (odd index 3, part (a)). C =\left(\sqrt{16}\right)^3=64 (positive base). D has no meaning: it needs \sqrt{-16}, an even root of a negative number. Check the denominator when the base is negative: odd is fine, even fails.

Fractional bases: root the top and the bottom

A root or a power of a fraction acts on the numerator and the denominator separately: \left(\dfrac{16}{25}\right)^{1/2}=\dfrac{\sqrt{16}}{\sqrt{25}}=\dfrac45. A negative exponent flips the fraction: \left(\dfrac{a}{b}\right)^{-k}=\left(\dfrac{b}{a}\right)^{k}.

Exact fractions. After ENTER, the F◂▸D key turns the decimal into a fraction: 27^((−)2÷3)ENTERF◂▸D gives \tfrac19.

Fractional bases

Evaluate each power. Express your answer as a fraction in lowest terms.

(a) \left(\dfrac{16}{25}\right)^{3/2}
Square-root the fraction, then cube:
\left(\sqrt{\tfrac{16}{25}}\right)^3=\left(\tfrac45\right)^3=\mathbf{\dfrac{64}{125}}
(b) \left(\dfrac{16}{25}\right)^{-3/2}
The negative exponent flips the answer to (a):
\dfrac{1}{\frac{64}{125}}=\mathbf{\dfrac{125}{64}}

A cube of known volume

A cube’s volume is V=e^3, so its edge is the number that cubes to V: e=V^{1/3}=\sqrt[3]{V}. Each face is a square with area e^2=\left(V^{1/3}\right)^2=V^{2/3}.

Two ways to type it. 32nd^100 or 100^(1÷3) both give 4.641588834. For the surface area, type it all at once and round once, at the end.
Example 4

A cube of known volume

A cube has a volume of 100\text{ cm}^3.

(a) Write a power that represents the edge length of the cube.
V=e^3, so
edge =V^{1/3}=\mathbf{100^{1/3}}
(b) Write a power that represents the surface area of the cube.
6 square faces, each e^2=V^{2/3}:
SA =\mathbf{6\left(100^{2/3}\right)}
(c) Use a calculator to find the edge length and surface area, each to the nearest tenth.
100^{1/3}\approx4.6416, edge \approx\mathbf{4.6} cm
6\left(100^{2/3}\right)\approx6(21.544), SA \approx\mathbf{129.3\text{ cm}^2}
Think Ali rounded the edge to 4.6 cm first, then found 6(4.6)^2\approx127.0\text{ cm}^2. What went wrong?
He rounded too early. Squaring 4.6 instead of 4.6416… loses accuracy, and multiplying by 6 makes the error bigger. Keep every digit (or use 6\left(100^{2/3}\right)) and round once at the end: 129.3.

Forcing a chosen exponent, and powers as radicals

Force an exponent of \tfrac1n: raise the number to the nth power first, then undo it with the nth root.
5=\left(5^2\right)^{1/2}=25^{1/2}\qquad5=\left(5^3\right)^{1/3}=125^{1/3}
Power → radical: the denominator becomes the index, the numerator stays a power.
a^{2/3}=\sqrt[3]{a^2}\qquad b^{-3/4}=\dfrac{1}{\sqrt[4]{b^3}}
Example 5

Forcing a chosen exponent, and converting to radicals

(a) Write 9 as a power with an exponent of \dfrac12, and again as a power with an exponent of \dfrac13.
Square 9 first, then undo it with a square root: 9=\left(9^2\right)^{1/2}=\mathbf{81^{1/2}}. Cube 9 first: 9=\left(9^3\right)^{1/3}=\mathbf{729^{1/3}}.

(b) Write each expression as an equivalent radical.

(i) x^{1/5}
x^{1/5}=\boldsymbol{\sqrt[5]{x}}
(ii) y^{3/8}
\left(\sqrt[8]{y}\right)^3=\boldsymbol{\sqrt[8]{y^3}}
(iii) z^{-1/4}
z^{-1/4}=\boldsymbol{\dfrac{1}{\sqrt[4]{z}}}
(iv) w^{-5/6}
\dfrac{1}{\left(\sqrt[6]{w}\right)^5}=\boldsymbol{\dfrac{1}{\sqrt[6]{w^5}}}

Writing Powers as Radicals

The exponent acts only on the base right under it. A coefficient or a minus sign in front stays outside the radical, unless brackets make it part of the base.

Outside: the exponent skips it
-a^{2/3}=-\sqrt[3]{a^2}5a^{2/3}=5\sqrt[3]{a^2}
Bracketed: it’s part of the base
(-a)^{2/3}=\sqrt[3]{(-a)^2}(5a)^{2/3}=\sqrt[3]{(5a)^2}=\sqrt[3]{25a^2}
!
Square the coefficient too when it’s inside the brackets: (5a)^2=25a^2, not 5a^2.
Example 6

Where the minus sign and the coefficient belong

Write each power as a radical.

(a) m^{1/5}
m^{1/5}=\boldsymbol{\sqrt[5]{m}}
(b) -n^{3/7}
The exponent applies only to n; the minus stays in front:
\boldsymbol{-\sqrt[7]{n^3}}
(c) (-p)^{5/3}
Here the base is (-p) itself:
\boldsymbol{\sqrt[3]{(-p)^5}}
(d) (-p)^{-5/3}
Negative exponent ⇒ reciprocal:
\boldsymbol{\dfrac{1}{\sqrt[3]{(-p)^5}}}
(e) 4s^{2/3}
The exponent applies only to s; the 4 stays in front:
\boldsymbol{4\sqrt[3]{s^2}}
(f) (4s)^{2/3}
Here the base is (4s):
\sqrt[3]{(4s)^2}=\boldsymbol{\sqrt[3]{16s^2}}
Think Are 4s^{2/3} and (4s)^{2/3} the same? Try s=2.
No. 4(2)^{2/3}=4\sqrt[3]{4}\approx6.35, but (4\times2)^{2/3}=8^{2/3}=4. The brackets change the base.
6

Writing Radicals as Powers

The same definition runs in reverse: match the index of the root to the denominator of the exponent, and the power inside to the numerator.

Radical → power
\sqrt[n]{x^m}=x^{m/n}
A plain \sqrt{\ } has index 2: \sqrt{x^5}=x^{5/2}
One over a radical
\dfrac{1}{\sqrt[n]{x^m}}=x^{-m/n}
A factor in the denominator gets a negative exponent.
Example 7

From radical form back to a rational exponent

Write each radical as a power in the form k^n, where n\in Q.

(a) \sqrt[4]{k^3}
Index → denominator, inside power → numerator:
\boldsymbol{k^{3/4}}
(b) \sqrt[6]{k^5}
\sqrt[6]{k^5}=\boldsymbol{k^{5/6}}
(c) \sqrt{k^7}
A square root has index 2:
\boldsymbol{k^{7/2}}
(d) \dfrac{1}{\sqrt[3]{k^5}}
In the denominator ⇒ negative exponent:
\boldsymbol{k^{-5/3}}
Think Write \sqrt{k} and \dfrac{1}{\sqrt{k}} as powers.
\sqrt{k}=k^{1/2} and \dfrac{1}{\sqrt{k}}=k^{-1/2}. The hidden index is 2 and the hidden power is 1.
✓

Key ideas

A fraction exponent is a root. The product law forces it: a^{1/2}\times a^{1/2}=a, so a^{1/n}=\sqrt[n]{a}.
Denominator = root, numerator = power: a^{m/n}=\left(\sqrt[n]{a}\right)^m=\sqrt[n]{a^m}. Take the root first.
Negative exponent = flip, never a negative answer: 27^{-2/3}=\tfrac19. An even root of a negative base isn’t real; an odd one is.
Watch the base. -n^{3/7}=-\sqrt[7]{n^3} but (4s)^{2/3}=\sqrt[3]{16s^2}. Going back: \sqrt[n]{x^m}=x^{m/n}.
